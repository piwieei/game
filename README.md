# 麻将大师

![麻将大师](https://placehold.co/1200x400/3b82f6/ffffff?text=Mahjong+Master)

## 项目简介

麻将大师是一个响应式在线游戏网站，专注于提供经典的中国麻将游戏体验。网站采用现代前端技术栈构建，确保在各种设备上提供出色的用户体验。

## 主要特点

- 🎮 嵌入式麻将游戏体验
- 📱 全响应式设计，适配移动设备和桌面电脑
- 🎯 直观的用户界面和流畅的导航
- 🏷️ 分类展示的游戏类别
- 🔄 特色游戏轮播展示
- 📊 集成Google Analytics追踪
- 🔍 SEO优化

## 技术栈

- HTML5
- Tailwind CSS
- JavaScript (原生)
- Google Analytics

## 功能亮点

### 响应式设计

网站采用移动优先的设计原则，通过Tailwind CSS的响应式类实现不同屏幕尺寸的完美适配：

- 移动设备上的汉堡菜单
- 流动式网格布局
- 自适应图片尺寸

### 游戏展示

- **特色游戏轮播**：自动轮播展示推荐游戏，带导航控制
- **游戏类别**：彩色卡片布局展示不同游戏类别
- **游戏列表**：网格布局展示游戏卡片，包含评分和分类标签
- **嵌入式游戏**：通过iframe直接在网站中体验游戏

### 用户交互

- 互动式导航菜单
- 轮播控制
- 图片悬停效果
- 按钮状态反馈

## 安装与使用

由于这是一个静态网站项目，您可以按照以下步骤运行：

1. 克隆仓库：
```bash
git clone https://github.com/yourusername/mahjong-master.git
```

2. 打开项目文件夹：
```bash
cd mahjong-master
```

3. 在浏览器中打开index.html文件或使用本地服务器运行项目。
